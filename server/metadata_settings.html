Automatic TV metadata — enabled

TV shows, posters, seasons, and episode descriptions load automatically from the free TVmaze public API. No account, token, or subscription is required.

The TV library remains usable if metadata cannot be retrieved. This provider is licensed under CC BY-SA and credited in the app.

Optional: The Movie Database (TMDB)

TMDB offers free API access for personal, non-commercial projects. If you want to use TMDB instead of TVmaze, you can add your own optional read-access token. This is not needed for automatic TV metadata. Your token is stored on your NUC, not in GitHub.

Checking metadata settings…

Get your free API Read Access Token at TMDB account → API settings. Do not paste it into chat or GitHub.

How matching works

One-Eyed Willie identifies shows, seasons, and episodes from existing file and folder names. TVmaze supplies posters and descriptions automatically, and TMDB is an optional alternative. It does not change, rename, or upload your media files.

Artwork and summaries are cached locally. If no match is found, you'll see the original title and a placeholder rather than incorrect artwork.
