The Movie Database (TMDB)

TMDB offers free API access for personal, non-commercial projects. Connecting a read-access token enables artwork and summaries. Your token is stored on your NUC, not in GitHub.

Checking metadata settings…

Get your free API Read Access Token at TMDB account → API settings. Do not paste it into chat or GitHub.

How matching works

One-Eyed Willie identifies the show, season, and episode from your existing file and folder names. TMDB supplies optional posters and descriptions. It does not change, rename, or upload your media files.

Artwork and summaries are cached locally. If no match is found, you'll see the original title and a placeholder rather than incorrect artwork.
