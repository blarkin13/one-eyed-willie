Direct connection setup

Yarr can use its secure Cloudflare connection without router changes. A direct peer-to-peer connection may require a UDP forwarding rule on some home networks. The steps below are for the current connection diagnostic only; direct video playback is still being implemented and verified.

Google Nest Wifi / Google Wifi — test UDP port 3478
  1. Make sure the Yarr Media server has a reserved home-network IP address in Google Home.
  2. Open Google Home → Wi-Fi → Settings → Advanced networking → Port management.
  3. Choose Add and select the device running Yarr Media (your Ubuntu server / NUC).
  4. Set protocol to UDP only. Enter 3478 for both the external and internal ports, then save.
  5. From a separate network, sign in to Yarr's direct connection test. Look for PASS and the host-network-sidecar diagnostic backend.
The server must already be running the fixed-UDP diagnostic update. Forwarding a port alone does not configure the application to listen on it.

Keep existing HTTPS/443 rules unchanged. Never forward TCP 8787 or TCP 18799 to the internet; those are local server and diagnostic control endpoints. You do not need to expose your media library to run the test.

If the connection test fails, remove the temporary UDP 3478 rule until the network setup is corrected. This port-forward test is optional, not a requirement for every Yarr installation. Yarr still needs automatic NAT traversal and fallback before direct playback can be considered production-ready.
