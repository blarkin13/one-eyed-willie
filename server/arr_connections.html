Integrations

Configure your media integrations. Each connection has its own settings and status.

SABnzbd

Checking…

Connect your download manager. Queue monitoring and controls are on the dedicated SABnzbd page.

Checking connection…

In SABnzbd, open Config → General and copy the full API Key, not the NZB Key. Use the local address reachable from this server. Your key stays in the server's private configuration and is never displayed.

Open SABnzbd dashboard to monitor downloads and control the queue.

SABnzbd continues handling downloads for Radarr and Sonarr. Yarr Media only shows status and provides explicit queue pause/resume controls; it does not add, remove, or delete downloads.

Plex watched history

Checking…

Import watched movies and episodes from your local Plex server into Yarr Media.

Checking connection…

Use a Plex token for the Plex user whose watched history you want. Plex must be reachable from the Yarr Media server on port 32400. The token is saved locally and is never shown again.

Imports only confirmed watched items, never removes existing watch history and never changes Plex. Matches are checked by movie title/year or TV show/season/episode number. Review the preview before importing.

OpenSubtitles

Find, download and enable subtitles without leaving the player.

Checking connection…

Get your API key from OpenSubtitles API Consumers. Credentials are saved privately on this NUC, not in GitHub. Existing credentials are never displayed.

Time Adrift

Checking…

Track how much time is spent paused and how much footage is rewound, separately for each movie or episode.

When enabled, a live Time Adrift counter appears in the upper-right corner whenever a video is paused. Totals are saved on this server and carried across viewing sessions.

Rewound time counts the length of deliberate backward seeks, not buffering or automatic quality changes. No media files are changed and no tracking data is sent outside this server.

Lyrics (LRCLIB)

Checking…

Show lyrics in the full-screen music player for songs that don't have their own.

Lyrics in your files always come first: a .lrc file next to the song, or lyrics in its tags. When this is on, other songs are looked up on LRCLIB, a free community lyrics database, and synced lyrics follow along as the song plays.

Leave it as https://lrclib.net, or use your own copy of LRCLIB (for example http://lrclib:3300 on this server).

Only a song's artist, title, album and length are sent to the LRCLIB address, once per song; answers are saved on this server. LRCLIB's lyrics are contributed by its users and are not licensed from songwriters or publishers, so it's your choice whether to use them.

How this works

Enter the LAN address and API key for each media manager. Credentials stay on the server; queues, history, searches, and monitoring are managed from their own Radarr, Sonarr, and SABnzbd pages.

Radarr manages movies; Sonarr manages TV series; Lidarr manages music artists and albums. Yarr Media can send a title to either service after you choose its folder and quality profile. Adding a title does not mean the media is available to play.

Other *arr applications have different content types: Readarr manages books, and Prowlarr manages indexers. They can be integrated separately when those features are supported; connecting them here would not add movie or TV browsing.
