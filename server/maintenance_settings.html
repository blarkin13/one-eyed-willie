Automatic maintenance

The server checks for due work during its overnight maintenance window (3 AM Central time). Weekly tasks run once per week; metadata refresh tasks run once every three days. Missed work runs during the next maintenance window after the server comes back online. Jobs process limited batches to protect playback performance.

Performance and storage

Quick media analysis reads video and audio stream properties with FFprobe. Extensive media analysis samples the audio of up to three videos per maintenance run. Preview generation extracts six 320-pixel images per video, with at most four new preview sets in each scheduled run. Previews appear when hovering or seeking on the video timeline. Analysis and preview files are kept in the private server data directory, not on your read-only media drive.

Old bundle cleanup is limited to generated One-Eyed Willie maintenance bundles. Cache cleanup removes stale generated artwork, WebVTT derivatives, and expired HLS sessions; it preserves downloaded subtitle files and manually corrected metadata matches. Database optimization preserves library and playback history.
